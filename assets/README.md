# Portfolio assets

- data.js: editable project content and activity timeline.
- app.js: page templates, hash routes, search, filters, quick navigation, and canvas animation.
- styles.css: design tokens, responsive layouts, and motion.
- portrait.jpg: original public profile portrait.
- favicon.svg: vector monogram.

The site is buildless. Serve the repository root with a static HTTP server. Publish index.html together with this assets directory.
